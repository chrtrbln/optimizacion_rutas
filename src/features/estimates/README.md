# Estimates

Own route distance, duration, fuel, fuel-cost, and kg CO2e estimation behavior. Preserve the fuel prices and emission factors used for historical calculations.

The C3 and C4 screens currently use editable assumptions and isolated sample operations from `sample-operations.ts`. The displayed fuel prices and emission factors are illustrative, not official DGEHM, IPCC, EPA, or GLEC values. Replace them with versioned data sources and immutable calculation snapshots when backend integration is authorized.
